# Procrastination_Robot
Code for my procrastination robot, which insults me if I'm procrastinating

# Features
- it connects to my webcam and insults me if i do 67
- since i'm using this on my raspberry pi's terminal, it connects to calcurse and insults me if i have something due soon

- I usually run this on raspberry pi terminal

# Built With/Things used
- Python
- OpenCV
- YOLO
- COCO's dataset
- GTTS
